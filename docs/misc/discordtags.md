!!! note "jei"
    ## All JEI Search Prefixes
    - **Prefix `@`**: Search by Mod ID
    - **Prefix `#`**: Search by Tag 
    - **Prefix `$`**: Search by Tooltip (Won't search anything that requires Shift to be pressed)
    - **Prefix `&`**: Search by Resources Location *[Needs to be enabled in the config!]*
    - **Prefix `%`**: Search by creative tab name *[Needs to be enabled in the config!]*
    - **Prefix `^`**: Search by color *[Needs to be enabled in the config & will also increase Ram usage!]*

!!! note "lava"
    ### Methods to generate infinite lava in ATM10
    1. **Fluid Drawer** (Functional Storage)
      - Make Dripping upgrades.
      - Right click the  fluid drawer with said Upgrades.
    2. **Extractor** (Xycraft)
      - Check JEI for the structure.
      - `?extractor` will also provide you with the setup.
    3. **Fire Seeds** (Mystical Agriculture)
      - Use the essence and combine it with a bucket in any crafting grid.
      - This will make a lava bucket.
    4. **Lava Bee** (Productive Bees)
    ### Methods to get lava which are technically not infinite.
    1. **Electric Pump** (Mekanism)
      - Go drain all the lava in the Nether.
    2. **Ranged Pumps**
      - Drain even more lava from the Nether.
    3. **Hose Pulley** (Create)
      - Drain all the lava?
      - if you have a pool with more than **10 000 source blocks** this method will create **infinite lava!**
    ### The best method.
    1. **Infinite Lava Cell** (ExtendedAE + KubeJS)
      - Put it in your ME Drive to have infinite lava available in your ME System.

    ### Apotheosis World Tiers in ATM10
    - Progress can be checked in the **Advancements** (default `L` or in the esc menu) after you found your first **Affix Item**.
    - After reaching a new World Tier you will have to active it in a new menu (default `Ctrl + T`).
    - Increasing your world tier means better quality gem and gear drops but will also improve enemy stats!

    ## FTBChunks Guide (refer to image after for visual result)
    ### Claiming Chunks:
    - Press `M` to open the **FTBChunks map**

    - Type `?extrachunks` in the discord chat

    - Type  `?ftbchunksserver`  in the discord chat

!!! note "ftbchunksserver"
    ## Keep chunks loaded even when players are offline - 2 Methods
    __**Ingame (need OP / admin)**__
    1. Open Inventory and click the`Claim Manager` button
    2. Click the `Server Settings` button (Purple Cogwheel)
    3. Scroll down to `Force-Loading`
    4. Change `Offline Forceloading Mode` set to `Always`

    __**Via Config**__
    1. **Stop the Server!** - The Config wont be saved if the Server is running
    2. **Find the config** - 
    __1.21.1+ (ATM10 and newer): __
    -> `<server>/config/ftbchunks-world.snbt` 
    __1.20- (ATM9 and older):__
    -> `<server>/world/serverconfig/ftbchunks-world.snbt`

    3: **Edit the setting** - `force_load_mode: default` to `force_load_mode: always`
    4: **Save!!!** - If you don't save it won't work

    __**Note**__: 
    ```diff
    - Sometimes you may need to Unclaim, and Claim + Forceload the chunks again for it to work.
    ```

!!! note "lag"
    ## How to identify lag
    ### (Neo)Forge
    - `/forge tps` (1.20.1 and below) / `/neoforge tps` (1.21 and above) will show you your worlds **Ticks per Second (TPS)**
    - By default the game runs at **20TPS** or **50ms per Tick**
    - If the TPS are **below 20** you will experience lag
    ### Spark
    - Type `?spark` in the discord chat
    - Run any of the given Commands
    - Click on the **URL** in Chat to open the results in your Browser
    - This will give you a detailed report on anything potentially causing issues
    ### Observable
    - Bind a key to the **Profiler** and run it
    - It will visually highlight blocks from **Green** to **Red**, **Good** to **Bad**
    - Observable will display the **Microseconds per Tick (µ/t)** (1000µs = 1ms) a block takes up
    - Click the **URL** in Chat to get a detailed list on what is using up the most µ/t
    - Send `?observable` in chat for a more detailed explanation.

    ### More Info
    For more information about those two mods, visit the links below:
    **Observable:** <https://www.curseforge.com/minecraft/mc-mods/observable>

!!! note "watchdog"
    **On the event of having a watchdog error:**
    If you are experiencing a watchdog error with your server (`java.lang.Error: ServerHangWatchdog detected that a single server tick took 180.00 seconds (should be max 0.05)`) you can edit the server.propeties file to prevent the watchdog crash. This should allow you to troubleshoot further to identify the source of the watchdog crash. 

    __This crash can be caused by:__
    * Exceeding your cpus percentage limits;
    * Running out of memory;
    * Various other in game sources like machines/quarries/logistics ticking too much. Try running the command `?lag` here and using the profilers provided by the bot to find the source of the problem.

    __Where and how to prevent the crash temporarily:__
